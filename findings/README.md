# findings

Research notes and reports from the Solana memecoin research bots.

Each bot writes only in its own folder:

| Folder | Bot |
| --- | --- |
| `chief-of-staff/` | Grok Bot |
| `security/` | Security Grok Bot |
| `execution/` | Execution Grok Bot |
| `narrative/` | Narrative Grok Bot |
| `smart-money/` | Smart Money Grok Bot |

Name files `YYYY-MM-DD-topic.md`, for example `2026-10-28-new-token-cluster.md`.
